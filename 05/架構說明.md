# 05 — Docker 微服務系統：架構與內容解析

專案位置：`_se/05/docker-microsystem/`

## 一、系統架構

```
                    ┌─────────────────────────────────────────┐
Browser ── :8080 ──▶│  nginx (Web Server + Reverse Proxy)     │──▶ 展示頁 (靜態 index.html)
                    │  - /            → 靜態前端               │
                    │  - /api/node/   → api-node:3000         │
                    │  - /api/python/ → api-python:5000       │──┐
                    │  - /api/rust/   → api-rust:8000         │──┤
                    └─────────────────────────────────────────┘  │
                                                                 ▼
                        ┌──────────────┐  ┌──────────────┐  ┌──────────────┐
                        │ api-node     │  │ api-python   │  │ api-rust     │
                        │ Node 20      │  │ Python 3.11  │  │ Rust + Axum  │
                        │ Express + pg │  │ Flask+psycopg│  │ tokio-postgr.│
                        └──────┬───────┘  └──────┬───────┘  └──────┬───────┘
                               └────────────────┼────────────────┘
                                                ▼
                                     ┌────────────────────┐
                                     │ db (PostgreSQL 16) │
                                     │ visits 表           │
                                     │ healthcheck 等待就緒 │
                                     └────────────────────┘
```

- **容器**：5 個（nginx / db / api-node / api-python / api-rust），全部掛在自訂 bridge 網路 `app-net`，以服務名稱互相解析。
- **資料持久化**：named volume `pgdata` 掛載 `/var/lib/postgresql/data`。
- **啟動順序**：後端三服務 `depends_on: db (service_healthy)`，等 `pg_isready` 通過才啟動；nginx 等三後端啟動。
- **對外端口**：只有 nginx 的 `8080:80`；資料庫與後端端口不對外暴露，僅供內網互連。

## 二、檔案內容解析

| 檔案 | 解析 |
|---|---|
| `docker-compose.yml` | 編排核心：定義 5 服務、環境變數（`DATABASE_URL`、`PORT`）、`app-net` 網路、`pgdata` volume |
| `nginx/Dockerfile` | 基底 `nginx:1.27-alpine`；複製 `nginx.conf` 到 `conf.d`、複製 `frontend/` 到預設站台目錄 |
| `nginx/nginx.conf` | `upstream` 定義三後端；`location /` 用 `try_files`  serve 靜態頁；`/api/<svc>/` 以 `proxy_pass …/` 剝掉前綴再轉發；`/nginx-status` 開 stub_status |
| `backend-node/Dockerfile` | 基底 `node:20-alpine`；`npm install --omit=dev` 後 `node server.js`，曝露 3000 |
| `backend-node/server.js` | Express 三路由：`/` 問候、`health`（`SELECT 1` 驗 DB）、`/api/users`（寫入一筆 visits 再回傳最新 5 筆） |
| `backend-python/Dockerfile` | 基底 `python:3.11-slim`；`pip install -r requirements.txt` 後 `python app.py`，曝露 5000 |
| `backend-python/requirements.txt` | `flask==3.0.3`、`psycopg2-binary==2.9.9` |
| `backend-python/app.py` | Flask 三路由，與 Node 版語義相同（`/`、`/health`、`/api/users`），DB 時間轉字串後回傳 |
| `backend-rust/Dockerfile` | Multi-stage：`rust:1.78-slim` 編譯 release → `debian:bookworm-slim` 只帶執行檔，曝露 8000 |
| `backend-rust/Cargo.toml` | `axum 0.7`、`tokio full`、`serde_json`、`tokio-postgres 0.7` |
| `backend-rust/src/main.rs` | Axum 三路由；`db_check` 用 `tokio-postgres` 直連驗證；`users` 做 INSERT 後 SELECT；以 `axum::serve` 綁定監聽 |
| `db/init.sql` | 容器首次啟動執行：建 `visits(id, service, created_at)` 表並寫入 3 筆種子資料 |
| `frontend/index.html` | 單檔展示頁：架構圖、三張服務卡（健康檢查＋讀 DB 按鈕，經 nginx 反向代理呼叫）、系統資訊 |
| `README.md` | 啟動／驗證／停止指令 |

## 三、請求流程（以 Node 健康檢查為例）

1. 瀏覽器 `GET http://localhost:8080/api/node/health`
2. nginx 命中 `location /api/node/`，`proxy_pass http://node_upstream/` 把前綴剝掉，轉發為 `GET /health` 到 `api-node:3000`
3. `server.js` 執行 `SELECT 1`，經 `DATABASE_URL` 連 `db:5432`
4. 回傳 `{"service":"api-node","status":"ok","db":"connected"}`，原路經 nginx 回瀏覽器，前端卡片顯示 OK

## 四、執行與驗證

```bash
cd _se/05/docker-microsystem
docker compose up --build        # 啟動，開啟 http://localhost:8080
docker compose down              # 停止
docker compose down -v           # 連資料庫一併清除
```

驗證端點：`/api/node/health`、`/api/python/health`、`/api/rust/health`、`nginx-status`。
